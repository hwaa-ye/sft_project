# Clean SFT-repair 统一评测 — 2026-07-11

## 实验配置

- 模型：Qwen3-8B Base + clean SFT-repair final LoRA
- 训练数据：25,704 条，完整样本长度不超过 2048 token
- 评测集：旧 mixed diagnostic set，484 条
- 生成：`max_new_tokens=2048`、`temperature=0.7`、`seed=42`
- 完整性定义：必须同时具有非空的 `<think>...</think>` 与
  `<answer>...</answer>`

## 全量 484 条：完成性结果

| 模型 | Accuracy（旧 gold） | 截断率 | 完成率 |
|---|---:|---:|---:|
| 旧 SFT | 67.77% | 27.48% | 72.52% |
| Clean SFT-repair final | 66.12% | 17.98% | 82.02% |

截断率下降 9.50 个百分点，相对减少约 34.6%。新模型的 87 条不完整输出全部属于
缺失 `</think>`；没有出现空 answer 或只有半个 answer 标签的情况。

全量 accuracy 不能直接作为结论：旧评测 gold 继承了历史答案抽取问题。484 条中，
393 条可从中间数据的 balanced boxed 可靠恢复；其中 54 条修复值与旧 gold 不同，
另有 91 条无法保守恢复。

## 解释

Clean SFT-repair 明显修复了短到中等长度样本的完成习惯，并同时提高正确率。主要收益
集中在 `<4k` gold reasoning 和 EduChat-Math；这与训练集移除半截 target 的因果假设
一致。

长难题能力仍然不足：`4k-8k` 截断率没有变化，`>8k` 仍有 83.33% 截断；
`amc_aime` 的 accuracy 和截断率还略有退化。首版 clean 数据只保留可在 2048 token 内
完整呈现的样本，因此这个结果符合预期：完成性问题得到修复，但长难题训练覆盖不足。

## 限制

- 该 mixed set 是内部诊断集，不是去重外部 benchmark。
- 新预测固定 seed=42；旧预测生成 seed 未记录，单次采样存在方差。
- 旧 inference 存在左 padding 切片问题，prediction 中混入部分 prompt；它不影响
  `<answer>` 抽取和完整性判断，但旧、新输出字符长度不能用于严格比较“是否变短”。
- 91 条无法可靠修复 gold 的样本仅用于全量完成性统计，不用于可信 accuracy 对比。

## 下一步

1. 使用相同评测脚本和 seed 评测 epoch 1、epoch 2，判断 final 是否为最佳 checkpoint。
2. 抽查 `old-right/new-wrong` 与 AMC/AIME 失败样本，确认是采样方差、长度不足还是能力退化。
3. 不立即进入 GRPO；先决定是否构建压缩后的高质量长难题数据。
4. 后续另建去重外部 benchmark，不能把当前结果表述为标准 benchmark 泛化。
