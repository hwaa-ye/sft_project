# SFT 训练数据 token 级诊断 — 2026-07-08

- 分词器: Qwen3-8B（真实分词器，非字符估算）
- 格式: 与 tokenize_dataset.py 的 format_math_sft 完全一致
- MAX_LENGTH: 2048（SFT tokenize 时的右截断上限）
- 数据文件: data/train_math_all.jsonl
- 总有效样本: 33599

> **「砍坏」= 样本 token 数超过 2048，被右截断后丢失了 `</think>` 或 `</answer>` 标签，即监督信号变成「半截推理、没有答案」。这类样本会教模型「可以不写完」。**

## 结论

- **21.2%（7122条）训练样本被 tokenizer 砍成半截、丢失答案标签**，这是「模型学会不写完」的直接监督来源。
- **78.8%（26474条）样本 ≤2048 token，结构完整**，构成 SFT-repair 的干净基础。
- amc_aime 砍坏率最高（比例视角的重灾区）；EduChat-Math 砍坏绝对数最多（数量视角的重灾区）。两者都需处理。
- 「超2048」与「砍坏」两列几乎相等 → 只要超长几乎必然丢答案（答案在末尾，一超长先被砍）。
